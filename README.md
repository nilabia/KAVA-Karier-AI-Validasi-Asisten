# KAVA - Karier AI Validasi Asisten

An AI-powered web platform that helps job seekers, from fresh graduates to career switchers, discover the most suitable career roles based on their CV profile through automated analysis.

## Features

- CV upload (PDF) with automatic analysis
- Top 3 Career Role Prediction using Deep Learning
- Skill Gap Analysis with progress bar
- AI Career Coach powered by Mistral AI
- Complete authentication system (email & Google OAuth)
- CV analysis history saved per user
